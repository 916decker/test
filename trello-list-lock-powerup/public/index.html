List Title Lock Power-Up

Protect your Butler Automations by preventing accidental list name changes

✅ Power-Up Active

The List Title Lock Power-Up is now active on this board!

How to Use:

  • Click on any list menu (···) to see lock options
  • Select "🔒 Lock List Title" to protect the list name
  • Select "🔓 Unlock List Title" to allow editing again
  • Locked lists show a 🔒 badge on the list

⚠️ Important Notes:

  • Only board admins can lock/unlock lists
  • Locked lists cannot be renamed by anyone (including admins)
  • To rename a locked list, unlock it first
  • This helps prevent Butler Automation breakage!

💡 Pro Tip:

Lock all lists that are used in Butler Automations to ensure your workflows never break due to accidental renaming!
